Panduan Setup

Setup Gateway Lokal

Panduan lengkap menghubungkan kamera RTSP dengan IP lokal (192.168.x.x) ke layanan streaming cloud RTSP2go menggunakan aplikasi Gateway.

Gambaran Umum

Mengapa IP Lokal Tidak Bisa Diakses Langsung?

Server RTSP2go berada di cloud/internet. Kamera dengan IP lokal seperti 192.168.1.100 hanya bisa diakses dari jaringan yang sama (LAN). Server kami tidak punya akses ke jaringan lokal Anda.

RTSP2go Gateway adalah aplikasi ringan yang berjalan di jaringan lokal Anda (PC, laptop, atau Raspberry Pi) dan membuat "jembatan" aman antara kamera RTSP lokal dan server cloud RTSP2go.

Cara Kerja

┌─────────────────────────────┐           ┌─────────────────────────┐
│   Jaringan Lokal (LAN)      │           │   Internet / Cloud      │
│                             │           │                         │
│  📷 Kamera RTSP             │           │  🌐 Server RTSP2go      │
│  192.168.1.100:554          │──────────▶│  rtsp2go.com            │
│                             │  tunnel   │                         │
│  💻 RTSP2go Gateway         │  aman     │  Browser pengguna       │
│  (berjalan di PC/RPi lokal) │◀──────────│  bisa menonton          │
└─────────────────────────────┘           └─────────────────────────┘
  1. 1Gateway App diinstal di PC/server yang ada di jaringan lokal yang sama dengan kamera
  2. 2Gateway membaca stream RTSP dari kamera lokal
  3. 3Stream di-forward ke server RTSP2go melalui koneksi terenkripsi (WebRTC/RTMP)
  4. 4Browser di mana pun bisa menonton stream langsung melalui RTSP2go

Instalasi — Windows

Tidak perlu install apapun. Cukup download dan jalankan.

1

Download file rtsp2go-gateway-windows-amd64.exe

Simpan di folder mana saja, misal C:\rtsp2go\

2

Buat file konfigurasi config.json di folder yang sama

config.json 
{
  "server_url": "wss://stage1-web-trs.ptozjk.easypanel.host",
  "api_key": "YOUR_API_KEY_FROM_DASHBOARD",
  "streams": [
    {
      "name": "kamera_depan",
      "rtsp_url": "rtsp://admin:password@192.168.1.100:554/stream1"
    },
    {
      "name": "kamera_belakang",
      "rtsp_url": "rtsp://admin:password@192.168.1.101:554/stream1"
    }
  ]
}
3

Jalankan Gateway

rtsp2go-gateway-windows-amd64.exe --config config.json

Atau klik dua kali file .exe jikaconfig.json ada di folder yang sama.

Instalasi — Linux / Ubuntu

Terminal 
# 1. Download binary
wget https://github.com/maulanaadam1/web-tr/releases/latest/download/rtsp2go-gateway-linux-amd64
chmod +x rtsp2go-gateway-linux-amd64

# 2. Buat konfigurasi
nano config.json
# (isi seperti contoh di atas)

# 3. Jalankan
./rtsp2go-gateway-linux-amd64 --config config.json

# (Opsional) Jalankan sebagai systemd service supaya otomatis saat boot
sudo nano /etc/systemd/system/rtsp2go-gateway.service
Lihat contoh systemd service file → 
[Unit]
Description=RTSP2go Gateway Service
After=network.target

[Service]
Type=simple
User=pi
WorkingDirectory=/home/pi/rtsp2go
ExecStart=/home/pi/rtsp2go/rtsp2go-gateway-linux-amd64 --config config.json
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
sudo systemctl enable rtsp2go-gateway
sudo systemctl start rtsp2go-gateway

Instalasi — Raspberry Pi

Raspberry Pi adalah pilihan ideal sebagai gateway permanen yang hemat daya (~5W).

# Jalankan sesuai file yang diunduh
./rtsp2go-gateway-linux-arm64 --config config.json

💡 Tips untuk Raspberry Pi

Gunakan Raspberry Pi OS Lite (tanpa desktop) untuk performa terbaik. Gateway bisa menangani 4-8 stream RTSP sekaligus pada RPi 4.

Konfigurasi Lengkap

config.json — semua opsi
{
  "server_url": "wss://stage1-web-trs.ptozjk.easypanel.host",
  "api_key": "ambil dari dashboard → Settings → API Key",
  "reconnect_interval": 5,        // detik, default 5
  "log_level": "info",             // debug | info | warn | error
  "streams": [
    {
      "name": "nama_unik_kamera",       // tanpa spasi
      "rtsp_url": "rtsp://user:pass@ip:port/path",
      "resolution": "1280x720",       // opsional, default auto
      "fps": 15,                       // opsional, default 15
      "transport": "tcp"              // tcp atau udp, default tcp
    }
  ]
}

Alternatif Tanpa Gateway App

Port Forwarding di Router

Forward port 554 (RTSP) dari router ke IP kamera. Gunakan IP publik router sebagai URL RTSP.

⚠️ Risiko keamanan — kamera terekspos langsung ke internet

Cloudflare Tunnel

Gratis, aman, tanpa port forwarding. Cocok untuk koneksi TCP/RTSP. Perlu akun Cloudflare.

cloudflared tunnel --url tcp://192.168.1.100:554

VPN (L2TP / WireGuard)

Sambungkan PC lokal ke VPS via VPN, lalu kamera lokal bisa diakses via IP VPN. Solusi paling stabil untuk deployment profesional.

FAQ

Apakah Gateway App gratis?

Ya, Gateway App adalah open source dan gratis. Anda membutuhkan akun RTSP2go (bisa yang free plan) untuk API key.

Berapa banyak kamera yang bisa dihandle?

Tergantung dari bandwidth upload dan CPU di lokasi lokal. PC biasa bisa menangani 4-16 kamera 720p. Raspberry Pi 4 bisa sekitar 4-8 kamera.

Apakah stream dienkripsi?

Ya. Koneksi antara Gateway dan server RTSP2go menggunakan WebSocket Secure (WSS/TLS). Stream tidak terekspos secara langsung ke internet.

Platform apa yang didukung?

Windows 10/11 (64-bit), Linux Ubuntu/Debian (amd64), Raspberry Pi OS (arm64). MacOS akan segera tersedia.

Siap Mencoba?

Download Gateway, daftar akun gratis, dan mulai streaming kamera lokal Anda ke web dalam menit.
