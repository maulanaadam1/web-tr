Panduan Format URL RTSP

Struktur Dasar

rtsp://username:password@IPaddress:554/path

Contoh Berdasarkan Merk

Generic / Umum

rtsp://admin:password@192.168.1.100:554/h264/ch1/main/av_stream

Dahua

rtsp://admin:admin@10.7.6.67:554/cam/realmonitor?channel=1&subtype=1

Hikvision

rtsp://admin:12345@192.168.1.210:554/Streaming/Channels/101

Samsung / Panasonic

rtsp://192.168.1.200/h264/media.smp

Tips: Sebagian besar kamera menggunakan port default **554**. Pastikan kamera Anda mendukung kompresi **H.264** agar bisa tampil lancar di browser.
