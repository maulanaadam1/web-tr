Panduan RTSP

rtsp://username:password@IPAddress:Port/path

Pola di atas adalah struktur dasar dari URL stream RTSP.

  • Pastikan kamera menggunakan kompresi H.264 agar WebRTC bekerja maksimal di semua browser (Tanpa perlu transcode server).
  • Kamera pada IP Lokal (seperti 192.168.1.10) dari dalam jaringan rumah Anda memerlukan port public forwarded atau tunnel agar dapat dijangkau oleh server cloud kami.
